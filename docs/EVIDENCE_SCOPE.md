# Evidence scope

Exact-setting limits, the finite-readout equality and the sufficient angle-error advantage are separate statements. The precision condition epsilon<=Q^2/(1+Q^2)^2 is sufficient, not a maximal necessary-and-sufficient readout tolerance. The policy attains the exact-setting whole-box minimax value; it is not asserted to be optimal for every individual device.

The angle-error formula bounds the policy, while the common-preset comparison bounds all presets from the other direction using the same error set. It does not solve the exact error-dependent minimax value. The supplied 1.5570 dB is a lower guarantee. An external review's approximately 10.9 dB sampled estimate does not establish the same-error global advantage and is excluded as a certified value.

Continuous conclusions rely on analytic arguments in the privately shared article. Finite controls, symbolic identities, rational numerical enclosures and plots have distinct verification roles. Neither a hash match nor a historical PASS establishes a theorem on its own. No hardware demonstration, metrology traceability or independent-user installation has been completed in this repository task.

This study is separate from the earlier four-maximum/five-component geometric theorem and from GNSS navigation research. Those proofs, papers and datasets are not copied here.
